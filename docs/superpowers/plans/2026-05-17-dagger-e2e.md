**Goal:** Add a Dagger e2e check that uploads a local file with the built `tus` CLI to an official `tusd` service.

### Task 1: Add Dagger E2E Smoke Check

**Files:**
- Modify: `dagger.dang`

- [ ] **Step 1: Replace `dagger.dang` with the Dagger e2e suite**

```dang
type Tus {
  let rust = rust

  new {
    self
  }

  pub cli: File! {
    self.rust.binary("tus")
  }

  let tusd: Service! {
    Dagger.container
      .from("tusproject/tusd:latest")
      .withExposedPort(1080)
      .asService(args: [
        "-host=0.0.0.0",
        "-port=1080",
        "-upload-dir=/srv/tusd/data",
      ])
  }

  pub e2e: Void! @check {
    Dagger.container
      .from("rust:latest")
      .withMountedFile("/usr/local/bin/tus", self.cli)
      .withServiceBinding("tusd", self.tusd)
      .withNewFile("/tmp/input.txt", contents: "hello from tus-rs dagger e2e\n")
      .withExec([
        "/usr/local/bin/tus",
        "--endpoint",
        "http://tusd:1080/files/",
        "--no-progress",
        "upload",
        "/tmp/input.txt",
      ])
      .sync

    null
  }
}
```

- [ ] **Step 2: Run the Dagger e2e check**

Run: `dagger call e2e`

Expected: PASS. Dagger builds the `tus` binary, starts the `tusproject/tusd` service, executes `tus --endpoint http://tusd:1080/files/ --no-progress upload /tmp/input.txt`, and exits without an error.
